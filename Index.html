Imagem para XLS

Envie uma imagem de uma tabela e receba os dados em Excel.

Sobre o Imagem para XLS

Uma ferramenta simples para transformar tabelas em imagem em planilhas Excel prontas para usar.

1

Envie a imagem

Arraste um print ou foto de qualquer tabela — recibo, planilha impressa, relatório escaneado.

2

Reconhecimento automático

O sistema identifica linhas, colunas e valores da tabela presente na imagem.

3

Baixe o Excel

Exporte o resultado em .xlsx, pronto para editar ou analisar.
